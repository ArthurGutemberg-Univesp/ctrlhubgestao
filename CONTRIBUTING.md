# Para organizar o GitHub do projeto:

1. Ninguém faz commit direto na branch main.  
2. Cada tarefa terá uma issue.  
3. Cada pessoa cria uma branch para sua tarefa.  
4. Sugestão para padrão de branch: feature/nome-da-tarefa, fix/nome-do-bug, docs/nome-do-arquivo.  
5. Todo commit precisa ter mensagem clara.  
6. Ao terminar, abrir Pull Request.  
7. Antes de começar a programar, atualizem o projeto.
8. Avisar no grupo
